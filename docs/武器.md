# 武器图鉴与数值

> 对应 `client/public/config/combat.json` 的 `weapons` 表；当前共 **36 把**。数值是**未叠加局内强化/天赋/角色永久成长**的基线值。
> 更新：2026-11-20。执行层：`client/src/domains/combat/Weapons.ts`；配置解析与校验：`client/src/domains/combat/config.ts`。

## 使用与获取

- **起始武器**：`pencil`（手枪），每局出生自带。
- **武器槽**：最多 2 把；`1` / `2` 直接装备对应槽，`X` 循环切换。
- **获取**：清房奖励和商店的武器候选都从**当前未持有**的全部武器里随机；商店一次陈列 2 把武器。
- **外观**：旧六把有独立外观；新增武器通过 `visualId` 复用「铅笔 / 星核 / 毒液 / 爆裂 / 导轨 / 冲锋枪」六套公共替身。

## 数值口径

- 单发伤害 = `balance.baseline.bullet.damage (10) × damageScale`。
- 冷却 = `balance.baseline.bullet.fireIntervalMs (250ms) × cooldownScale`。
- 弹速 = `520 × speedScale` px/s；近战无弹速。
- 表内 DPS 是**名义单体 DPS** = 单发伤害 × 弹丸数 ÷ 冷却；分裂、连锁、溅射、多段、回旋等额外命中不计入，实际输出通常更高。
- 近战能量消耗恒为 0；远程按 `staminaCost` 消耗。

## 武器特效速查

| 特效 | 表现 |
|---|---|
| 连锁 chain | 命中后向附近目标放电；`pulse` 为历史专属字段，其余走 `traits.chain`。 |
| 中毒 poison | 按 tick 持续扣血；`venom`/`mop`/`chem_sprayer` 走不同配置字段。 |
| 减速 slow | `smg` 命中减速 25%/1.2s；`cryo_sprayer` 减速 45%/1.5s。 |
| 溅射 splash | `flare` 92 半径/60%；`model_rocket` 120/60%；`firework_launcher` 70/30%。 |
| 穿透 pierce | `rail` 3 目标、`set_square_sniper` 4、`nail_gun`/`bubble_gun` 2、`laser_pointer`/`basketball_boomerang` 全部。 |
| 爆发 burst | 一次扳机连发多枚：`auto_pencil_smg` 3 连、`scissors` 2 段。 |
| 回旋 boomerang | `basketball_boomerang` 去程/回程都能命中。 |
| 追踪 homing | `paper_plane` 轻追踪；`magnetic_frisbee` 弹墙 + 轻吸附。 |
| 弹墙 bounce | `tennis_ball` 4 次、`magnetic_frisbee` 3 次。 |
| 引信 fuse | `grenade_launcher` 命中或 0.6s 后爆炸。 |
| 分裂 split | `split_dart` 命中分裂 3 枚；`firework_launcher` 命中/爆炸分裂 6 枚环形。 |
| 吸血 lifesteal | `lifesteal_syringe` 实际伤害的 20% 回血。 |
| 击退 knockback | 近战 `eraser_maul`/`broom`；远程 `double_barrel`/`sonic_horn`。 |
| 消弹 destroyShot | `glowstick` 挥砍消除敌方弹丸。 |

## 备注

- `pulse` 的弹丸数固定为 1（`deriveStats` 对 `pulse` 有特判），即使配置写了别的值。
- 近战伤害在扇形内按 `range` / `arcDeg` 判定，`effectMs`/`swingMs` 控制挥砍表现。
- 局内强化、天赋与角色永久成长会改变伤害/冷却/弹速/弹丸/散射；本表只列武器自身的 `damageScale` / `cooldownScale` 基线。
- 新增武器如果还没有独立美术，会复用六套公共外观；换真美术时改 `visualId` 或资源清单，不需要改战斗逻辑。
