### 浏览器验证入口与方法

白箱入口：`/test.html?arena=d4_dream_story`。该场使用内存档案与 C1 事件桩，不读取战斗内部状态，不改变真实玩家档案。

验收使用独立 Edge 会话，通过 Node 24 原生 WebSocket 连接 CDP；没有安装浏览器测试依赖。鼠标与键盘用 CDP 输入事件实际派发。后台用独立标签页切换产生真实 `visibilitychange`；缺图通过临时移除测试页纹理验证；写盘失败通过内存存储后端主动抛错验证。动画边界竞争另通过同一浏览器中的 UI 时间推进验证。

为避免其他成员并行修改代码使验收页面热重载，验收会话屏蔽了自身的 Vite HMR WebSocket。这只作用于该浏览器测试页，没有修改产品代码或开发服务器。
