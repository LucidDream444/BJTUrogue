## 实战场

WASD移动、鼠标瞄准/左键开火；1–6切换六种武器；`[` / `]`切换角色。默认小红果并开启保护，便于观察跳跃与360°枪械。

`B`番鸭、`C`双猫、`M`混合，`O`切换障碍，`I`切换保护，`H`回满，`0`清场，`P`暂停，`R`重置，`Esc`回测试菜单。相同操作也提供屏幕按钮。

建议先用番鸭场站在预警线上，蓄力后横移，检查方向锁定；再开启障碍观察提前停止。双猫场中向旋风附近射击，检查弹道弯曲，关闭保护观察伤害；击败猫后观察正常化和虚空退场。

## 角色与故事

小红果仍使用旧 `scholar` 身份，技能机制和成长数值沿用旧档。故事场提供三角色选择、开场与结局入口，`Enter` / `Space` / `→`下一张、`Esc`跳过当前段；故事关闭后可以回菜单。故事中的输入不会穿透到场内操作。

测试场是独立 `test.html` 产物，正式运行不依赖测试代码。美术源文件和全部资源帧表见[交付说明](art/dream_20261102/README.md)。

## 第八层联调

进入后看完或跳过开场，就会到达8F心魔房。默认开启测试保护，可用面板的三角色按钮开新局。

`B`通过正式伤害入口击败心魔，应播放对应结局；`K`击败玩家，应直接死亡结算；`T` / `Y`分别触发心魔先死或玩家先死的同帧情况，都应按死亡结算；`G`开关保护。右侧面板同时显示角色、楼层、流程状态、金币和统计。所有收益均在内存测试档内，选角色重开会清零。

建议桌面浏览器窗口至少1280像素宽，以完整显示D3固定布局的右侧控件。实战场与剧情覆盖层会随窗口尺寸调整。
