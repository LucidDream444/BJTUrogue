# 局外成长设计

> 归属：**D4 局外成长与存档**。现行版本：2026-10-22。
>
> 所有成长数值在 [`client/public/config/meta.json`](../client/public/config/meta.json)，本文解释结构与玩法，不复制具体数值。

## 一、核心结构

现在只有三个角色：新生、大鹅、图书委员。

每个角色固定为：

- **1 个被动**：解锁角色后永久生效，不单独升级。
- **1 个主动技能**：固定四级。
- 技能 1 级随角色解锁自动获得。
- 技能 2 / 3 / 4 级各花一次金币。
- 三个角色使用同一个技能等级字段、同一个升级按钮和同一条升级流程。

不再有独立的生命、能量、护盾成长树，也不再有全局技能列表。

## 二、角色身份

| 角色 | 固定被动 | 主动技能 | 定位 |
|---|---|---|---|
| 新生 | 稳扎稳打：生命上限 +10% | 奋笔疾书 | 短时间高攻速输出 |
| 大鹅 | 鹅步生风：移动速度 +20% | 展翅突进 | 高速位移，穿敌后强化 |
| 图书委员 | 馆藏检索：能量恢复 +50% | 馆藏借阅 | 放置参考书与阵地火力 |

## 三、技能升级

### 新生：奋笔疾书

按 `Space` 获得一段时间的高攻速。

- 1 级：基础攻速爆发。
- 2 级：提高攻速、持续时间，缩短冷却。
- 3 级：继续提高攻速与覆盖率。
- 4 级：进一步强化到高攻速，**不增加额外机制**。

重复释放刷新持续时间，不叠层。

### 大鹅：展翅突进

按 `Space` 向瞄准方向突进并获得短暂无敌。

- 1 级：基础突进。
- 2 级：提高沿途伤害与无敌时间，缩短冷却。
- 3 级：继续提高沿途伤害与无敌时间并缩短冷却。
- 4 级：沿途伤害大幅提高，并在穿过敌人后获得 3 秒攻速。

4 级机制：

- 每穿过一名不重复敌人，攻速提高。
- 最多计算五名敌人。
- 再次突进会替换上一轮尚未结束的加成。

### 图书委员：馆藏借阅

按 `Space` 在鼠标位置放置一本参考书，自动攻击附近敌人。

- 1 级：一本参考书。
- 2 级：提高书页伤害、频率，缩短冷却。
- 3 级：提高持续时间、伤害与频率，继续缩短冷却。
- 4 级：技能改为两层充能。参考书没有同时存在数量上限，但会按持续时间过期。

4 级机制：

- 最多储存两次充能。
- 每按一次 `Space` 消耗一层充能并放置一本书。
- 开局直接拥有两层充能，可以连续放置两本书。
- 充能恢复后可以继续放置，场上没有两本上限。
- 离开当前房间后，旧参考书全部移除；充能状态保留。

## 四、升级数据

每个角色在 `meta.json` 中拥有统一形状：

```text
skill:
  id
  name
  description
  kind
  upgradeCosts[3]
  levels[4]
```

存档只记录已经买过的升级次数：

```text
upgrades["student:skill"] = 0..3
upgrades["athlete:skill"] = 0..3
upgrades["scholar:skill"] = 0..3
```

字段缺失表示技能仍是 1 级。这样 1 级不占额外存档字段，暂停菜单的“升级次数”也可以直接使用该值。

## 五、存档迁移

存档 schema 当前为 **v4**。

v1 → v2 处理：

- `armor` → `maxShield`
- `magic` → `maxEnergy`
- 删除社团长选择

v2 → v3 处理：

- 旧成长线退出战斗。
- 按旧成本曲线把已经消费的金币退回。
- 清空旧升级与旧技能解锁列表。
- 所有已解锁角色的新技能从 1 级开始。

v3 → v4 处理：

- 增加单调递增的 `revision`，供后续云存档比较新旧版本、去重上传和阻止旧请求覆盖新档。
- 本地写入失败时 revision 仍会前进；之后“重试保存”写出的必须是当前最新进度。
- 旧档的 revision 从 0 开始，不拿统计次数或游戏进度充当同步版本号。

## 六、界面

升级页只有一个技能卡：

- 当前技能等级
- 四个等级的名称与效果
- 下一级价格
- 一个统一的“升级”按钮
- 角色解锁区域

暂停菜单和战斗 HUD 显示当前角色唯一技能的名字与等级。

设置中的显示模式以浏览器实际 Fullscreen API 状态为准：进入 / 退出全屏事件发生后
才写回本地；玩家按 Esc 退出全屏也会恢复为“窗口”。分辨率不提供，因为画布使用
`Scale.RESIZE` 跟随窗口。

## 七、战斗键位

- `Space`：释放当前角色技能。
- `X`：循环切换已获得武器。
- `1 / 2`：直接装备对应武器槽。

## 八、后续待定

- 三个技能的数值需要试玩校准。
- 参考书目前使用直接快速攻击与光束反馈，后续可升级为真正的实体书页抛射物。
- 技能音效尚未接入专用声部。
- 角色专属技能美术与图标仍使用现有校园 UI 资源。

## 九、云存档准备

首版仍保证本地离线可玩。后续云存档采用“本地先成功，云端异步同步”，不能在战斗循环里等待网络。

- `ProfileStore` 继续以本地档为运行时权威数据。
- `ProfileStore.snapshot()` 提供深拷贝，供同步层上传，避免网络层直接修改运行中的内存档。
- 同步层订阅 `ProfileStore` 的 `'updated'` 事件，并检查 `lastError`；本地都没写成功时不得上传。
- 每次修改只增加一次 `revision`。登录拉取、断网重试、冲突处理都围绕该字段展开。
- 音量等设备偏好默认只存本地；角色解锁、技能等级、金币和统计属于云端同步范围。
- 战斗中的临时状态不进入局外云档；只在结算和局外修改后触发同步。

服务端字段、鉴权与冲突接口尚未冻结，D5 实现前以
[`云存档接口草案.md`](云存档接口草案.md) 为讨论基线。
