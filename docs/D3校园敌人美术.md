# D3 校园敌人美术（2026-10-16）

本次按用户确认采用 **Pillow 本地逐帧像素绘图**，没有调用图片模型或 API。

设计规格：把史莱姆换为带折痕与浅蓝横线的米白纸团，死亡时纸摊开、撕分后揉成更小纸团；
把蘑菇肉盾换为封面标题严格为“计组”的厚课本，字色为金色，配深色铭牌提高辨识度；强调成叠书页与厚书脊，跳跃靠近玩家，
蓄力后落地砸击。透明背景、固定画布与地面锚点。首领只保留矩形占位。

| PNG（相对 `client/public/assets/sprites/enemies/`） | 帧规格 | 帧序号 |
|---|---|---|
| `enemy_splitter_paper.png` | 64×64，4 列 × 8 行 | 0–7 纸团晃动；8–15 展开成 2 团；16–23 展开成 4 团；24–31 末代展开淡出 |
| `enemy_tank_textbook_walk.png` | 96×96，4 列 × 4 行 | 0–15 蓄力、跳起、落地、回弹 |
| `enemy_tank_textbook_attack.png` | 96×96，4 列 × 4 行 | 0–7 下砸前摇；8–15 落地与恢复 |

三代纸团共用图集，大小仍由 `enemies.json` 的 `visualScale` 决定。
课本保留 `kind: 'tank'`、`enemy_tank_idle` / `enemy_tank_walk` 逻辑 key 和原有战斗数值。
课本不会左右镜像，避免封面汉字反写。跳跃位移画在帧内，不移动物理碰撞圆。

纸团死亡使用有容量上限的独立视觉池，不复用尸体作为动画对象；尸体照常摘除物理体。
有孩子的动画按现有 `splitDelayMs` 播放，2 → 4 的子代数、出生间隔和血量伤害保持原配置。
暂停与顿帧时使用游戏逻辑时间，死亡帧与分裂队列一起暂停。

首领仍由 `requestBoss()` 创建，保留血条、阶段、攻击与事件接口：

| 身份 | 现有流程 | 占位 |
|---|---|---|
| 蘑菇首领 | 第 1 层 | 白色长方形 |
| 霜翼领主（当前配置显示“霜翼使徒”） | 第 2 层的远程首领 | 蓝色长方形 |
| 蜘蛛女皇（当前战斗配置显示“终焉蛛王”） | `finalBoss: true` | 紫色长方形 |

旧首领的 6 个资源 key 保留并标为 `placeholder: true`，启动时不请求已删除的图片，
也不注册旧序列帧。首领从出生起使用占位，普通课本与首领复用池槽位时重置 tint。

重新生成全部 PNG 和预览：

```powershell
python client/src/test/arenas/D3/tools/draw_campus_enemies.py
```

需要 Python、Pillow 和 Windows 中文字体（黑体或微软雅黑）；运行时与构建均不需要 Python。
预览输出至被忽略的 `artifacts/d3-campus/`，实际游戏只加载 `public/assets/` 中的 PNG。

运行验证场：`http://localhost:5173/test.html?arena=d3_campus_art`。
`P` 击杀当前纸团查看展开、分裂；`R` 重置；玩家默认无敌。
原有 `splitter_chain`、`tank_grind` 测试场也可继续验证战斗行为。
