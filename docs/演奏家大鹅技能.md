# 演奏家大鹅“演奏”技能设计

> 归属：D1 战斗核心。角色表现复用现有大鹅分层美术，但使用独立角色 ID `performer`。
> 数值唯一真值：[`meta.json`](../client/public/config/meta.json) 的 `performer.skill`。

## 玩法定位

“演奏”是一段主动放弃枪械输出的节拍强化状态。玩家用魔力维持演奏，换取范围伤害、增伤、移速和护盾，靠持续命中节拍维持双色叠层。它不按时间自动结束：魔力耗尽会自动停止，也可以按 `F1` 主动停止；停止后仍在有效期内的红/蓝效果会保留。

## 输入与状态

| 状态 | Space | 鼠标左键 |
|---|---|---|
| 未演奏 | 开始演奏 | 正常使用武器 |
| 演奏中 | 红歌 | 蓝歌 |
| 演奏中按 `F1` | 停止演奏，保留未过期歌曲层数 | — |

- 两个歌曲输入各有独立的 200 ms 内置冷却。输入按“按下边沿”处理，按住不会自动连奏。
- 每次成功触发歌曲都会扣除该阶的 `manaCost`；被内置冷却挡掉的输入不扣魔力。
- 演奏期间魔力不自然恢复。剩余魔力不足一首歌时，最后一首扣掉全部剩余魔力，随后自动结束。
- 演奏开启后立即停止当前射击；整段演奏期间武器开火入口被屏蔽。
- 演奏没有技能冷却，也没有时长上限；只有魔力耗尽或按 `F1` 才会结束。
- 演奏结束后自动解除缴械；再次按 `Space` 可以立刻开始下一段演奏。
- 清房、换房间、死亡或场景销毁会结束“演奏中”状态，但不会提前清空尚未到期的歌曲层数。

## 节拍判定

节拍条每秒从左到右送出一枚实心节拍圆。前 800 ms 为移动段，最后 200 ms 为命中窗；进入命中窗时实心圆停在与右侧空心圆重合的位置。

```text
周期相位 = (当前逻辑时间 - 本段演奏开始时间) mod 1000
命中节拍 = 周期相位 >= 800
```

- 使用逻辑时钟，不看渲染帧数；暂停与顿帧期间节拍条也停住。
- 同一秒的两色输入互不共享冷却，可以在同一个节拍窗内先按 `Space` 再点左键。
- 未命中节拍仍造成该色保底效果；不会加层，也不会刷新已有的同色层数计时。

## 红歌

- 每次输入对玩家周围半径内的所有敌人造成一次范围伤害。
- 命中节拍时增加 1 层红歌并刷新红歌有效期；已有 5 层时仍刷新，但不再增加。
- 每层红歌提供独立于武器的自身伤害倍率。演奏期间该倍率主要强化红歌范围伤害，演奏结束后仍会强化枪械，直到红歌层数过期。
- 命中节拍后的范围伤害会随当前红层层数提高；保底红歌固定使用基础伤害。

## 蓝歌

- 每次输入恢复护盾；命中节拍时增加 1 层蓝歌并刷新蓝歌有效期。
- 每层蓝歌提供移速和临时护盾上限；层数过期后上限下降，当前护盾按上限截断。
- 保底蓝歌只提供固定护盾恢复，不享受层数加成。

## 独立叠层

- 红色、蓝色各自维护层数和过期时间，最多 5 层。
- 某色命中节拍会刷新该色的完整有效期；另一色的计时不受影响。
- 某色有效期结束时该色所有层数一起消失。这样 HUD 只显示“红 3/5”“蓝 4/5”和一个倒计时，玩家能直接判断是否需要续拍。

## 配置字段

```text
kind: "performance"
beatPeriodMs            节拍周期
beatHitWindowMs         节拍命中窗
songCooldownMs          红/蓝各自输入冷却
manaCost                每首歌魔力消耗
maxStacks               单色最大层数
stackDurationMs         单色叠层有效期
redDamage               红歌保底范围伤害
redDamagePerStackPct    每额外一层提高红歌伤害
redRadius               红歌范围
damageBonusPctPerStack  每层红歌提供的自身增伤
moveSpeedPctPerStack    每层蓝歌提供的移速
shieldPerStack          每层蓝歌提供的护盾上限
blueShieldRestore       蓝歌保底护盾恢复
```

## 表现

- 演奏条固定在屏幕底部中央，高于世界实体与常规战斗 HUD。
- 实心节拍圆与右侧空心圆等大；进入命中窗时二者重合，目标环变亮。
- 屏幕始终显示红歌层数、蓝歌层数、各自剩余时间和当前/上限魔力。
- 红歌使用红色扩散环表现范围；蓝歌使用较短蓝色扩散环。表现只复用几何对象，不需要新美术资源。

## 演奏音乐

演奏开始时暂停普通战斗 BGM，循环播放 `bgm_performer_stage_loop_4bar_60bpm`；停止演奏或魔力耗尽后停止该循环并恢复普通 BGM。

- 60 BPM：每拍正好 1 秒，与演奏条节拍周期一致。
- 四小节、16 拍、16.000 秒。
- 单声道 22.05 kHz、16-bit PCM WAV，循环点按采样精确，不使用会带编码填充的 MP3。
- 每拍都有木鱼/底鼓重音，每小节第一拍更强，方便用听觉判断演奏条位置。
- 生成脚本：`client/src/test/arenas/D1/tools/generate_performer_loop.py`。
