# D3：催化喷洒怪

入口：正式游戏的战斗房间会刷出；主菜单图鉴可查看数值。
独立验收场：开发服务启动后打开 `/test.html?arena=liquid_grind`。

## 机制

- 怪物接近玩家后保持距离，标出锁定的地面落点，前摇结束喷出一组催化液。玩家移动可避开预警。
- 玩家踩中液滩，**该液滩立即消失**并获得沾液状态。快速穿过也按移动线段检测。
- 沾液期间移速乘 1.55，接触敌人造成 80 点伤害，同一敌人的接触攻击间隔 650 毫秒。
  此效果不附赠接触免伤；未被撞死的敌人仍能按原规则伤害玩家。
- **实际移动**累计每 500 毫秒消耗 3 点生命。不会先扣护盾，不被受击无敌挡住，也不会产生硬直、打断移动或给玩家额外无敌。
- **静止累计 3000 毫秒清除**，可以分段累计，中途移动不重置已经累计的进度。
  面向变化和射击不影响累计；顶着墙但实际没移动时算静止。
- 再次踩液仍消费地面液滩，但不叠加效果、不刷新清除进度。
- 清除后恢复原移速，已有角色成长和局内升级不会被覆盖。死亡、换层、重开均清理相关状态。
- 怪物死亡后，已经喷出的液体仍留在地面，直到被踩掉或自然消失。
- 暂停、失焦暂停和顿帧期间不推进效果；同一渲染帧不重复结算，长帧最多推进 1/30 秒。

## 调参

所有玩法数值位于 `client/public/config/enemies.json` 的 `enemies.sprayer`：

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| `hpValue` | 8 | 8 发基线子弹的生命，随难度派生 |
| `speed` / `radius` | 72 / 22 | 基础移速、物理半径 |
| `spray.range` / `keepDistance` | 320 / 220 | 喷洒射程、保持距离 |
| `spray.windupMs` / `cooldownMs` / `recoverMs` | 900 / 3600 / 500 | 前摇、起手间隔、恢复 |
| `spray.puddlesPerSpray` / `puddleRadius` | 4 / 25 | 每轮液滩数、单滩判定半径 |
| `spray.spreadDistance` / `lifetimeMs` | 54 / 12000 | 扩散距离、液滩寿命 |
| `spray.maxPuddles` | 48 | 全场液滩池上限 |
| `coating.speedMultiplier` | 1.55 | 沾液时乘在最终角色移速上的倍率 |
| `coating.cleanseStillMs` | 3000 | 所需累计静止时间 |
| `coating.stillSpeedThreshold` | 6 | 排除浮点抖动的实际移动速度阈值 |
| `coating.drainIntervalMs` / `drainDamage` | 500 / 3 | 移动耗血节拍、每次生命代价 |
| `coating.ramDamage` / `ramCooldownMs` | 80 / 650 | 接触攻击伤害、同目标节拍 |

正式房间数量由 `combat.json` 的 `arena.initialSprayers`（当前 0.75）乘房间预算和难度敌人数后取整。
颜色及气泡数位于 `fx`；不需要修改 TypeScript 即可调平衡。

## 接线与资源

- C2：`EnemyKind` 增加 `sprayer`，配置加载器校验喷洒怪整表。血量仍由基线子弹伤害派生。
- C1：`player_liquid_changed` 发布玩家 id、激活状态、移速倍率和静止进度；`player_liquid_drain` 发布玩家 id、来源 id、生命代价及逻辑帧/时间。
  D1 已订阅并应用；D3 不读取或修改 D1 的玩家内部状态。
- 碰撞回调只登记接触 id，在 `WORLD_STEP` 后统一处理伤害；同目标冷却、同帧去重及回池配对清理均有守卫。
- `LiquidField` 和 `SprayerBrain` 为纯逻辑，不依赖 Phaser；`LiquidFx` 负责地面预警、液滩、气泡、沾液拖尾和累计进度环。
- 六帧透明像素图：`client/public/assets/sprites/enemies/enemy_sprayer_idle.png`。
  三组短音效：`client/public/assets/audio/sfx/enemies/sfx_liquid_{spray,pickup,cleanse}.{ogg,mp3}`。
  全部经 `assetManifest.ts` 加载，音效使用固定声部池。
- 可复现制作脚本：`client/src/test/arenas/D3/tools/draw_sprayer.py`（Pillow + ffmpeg，本地绘制及合成，无外部 API）。

## 验收

`WASD` 移动，左键射击；专用场内 `P` 在脚下喷液，`G` 重摆怪物并复活，`SPACE` 暂停，`R` 重启。
界面显示液滩数、实际耗血、实际接触命中数与静止累计。

自动测试覆盖前摇锁定、绕墙、死亡取消、恢复冷却、池化复位、液滩容量/寿命/消费、累计静止、
移动耗血、重复帧/长帧、接触冷却、暂停、护盾/无敌分离及单次死亡。
浏览器同时验证专用场与正式玩家的完整接线，含正式刷怪和换层清理。

本次结果：完整串行单测 **756/756（45 个文件）** 通过，`npm run lint`、`npm run build`（含类型检查）通过；
专用场 9 项、正式玩家 13 项浏览器检查通过，包括实体碰撞、死亡、连续三次重启且监听器不重复。
六份 Ogg/MP3 文件均经浏览器音频解码验证。并发检查时原有地图生成耗时项曾超过阈值，
未修改阈值，单独及完整串行复测均通过。
