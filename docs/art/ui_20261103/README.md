# 2026-11-03：笔记本图鉴与校园三选一 UI

本轮按用户给定三个素材目录接入真实界面。按用户确认，代码、素材与交付文档一起提交 main，供组员同步。

## 运行入口

- 校园主菜单 → 升级：深蓝皮革书封、浮空法典、四阶节点与真实属性对比。允许查看未解锁角色并购买，升级对象不修改出战角色。
- 校园主菜单 → 图鉴：银白书页、每页六张目录卡、普通/首领筛选、真实怪物动画与战斗数值。详情显示全部属性；Enter 详情，Esc 逐层返回。
- 正式战斗清房 → 三选一：校园樱花标题、三色插画卡、独立浅色说明区。保留点击/1/2/3选择、防重复领取、真实数值对比和暂停流程。

## 素材来源与制作

- `1793698131289-92qwihroaw`：升级和图鉴的风格参考，法典、技能图标、蓝色按钮直接裁自参考图。
- `1793698311485-3sin9g4efl9`：绘画版书本与运动鞋奖励插画。
- `1793698547689-7piosv8gb4n`：像素校园校门、便当、课本、篮球奖励卡。
- 原始参考图实际为 **2048×2048**。提取工具先归一到坐标设计基准 **1600×1600**，再裁图、做透明边缘；不能直接把1600坐标用于2048原图。此处修复了原先混入相邻素材、边框割裂、说明压插画的问题。
- 奖励卡原画的纸面文字区域向下延长70像素，顶部插画不拉伸；卡名、说明、堆叠数及前后数值由DOM实时渲染。鼠标/键盘焦点使用沿实际轮廓的柔光。
- 深色空白书封、浅色空白书页通过 `codex-image2-5` 上传用户参考图生成：模型 `gpt-image-2.5`、请求 `1K`、质量 `high`。原始返回分别1254×1254、1024×1024；浅色书页经过书脊对齐重组为1600×900。完整提示词与参考图保存在 `client/public/assets/ui/codex/`。
- 游戏只加载 `ARCHIVE_ART` / `REWARD_ART` 注册的运行时切片，概念图不注册。新增清单是纯数据，所有路径仍由 `assetManifest.ts` 管理。

## 复现切图

`client/tools/art/extract_archive_ui.mjs` 与 `extract_reward_ui.mjs` 使用 Sharp。工具只用于美术构建，不增加游戏运行时依赖。可在有 Sharp 的 Node 环境执行，或用 `ARCHIVE_SHARP` 指定本机现有 Sharp 入口模块的绝对路径；脚本不包含个人运行时路径。

## 全套页面扩展

2026-11-03追加：成就、说明、出发准备、设置、退出确认，以及战斗暂停菜单均采用相同笔记本皮肤。成就/说明使用银白书页，其余采用深蓝皮革；复用已注册图片，无新增网络字体或运行时依赖。

- `NotebookPanels.ts`：共享页面构建器。设置更新已有显示对象；音量通过完整世界矩阵反变换，支持窗口缩放及战斗相机。全屏仅由真实用户点击触发，选中态跟随浏览器事件。
- `helpContent.ts`：基础操作、战斗指南文案唯一来源，旧面板与新手册共用。
- 主菜单不再保留旧弹窗布局；旧设置/说明辅助组件仍可供现有测试设施使用。
- 真实浏览器12组交互验证，报告为 `artifacts/archive-ui/pages-verification.json`。测试购买使用内存档，正式游戏检查使用独立浏览器上下文。
- 实拍：`page-start.png`、`page-achievements.png`、`page-help.png`、`page-settings.png`、`page-quit.png`、`page-pause.png`，另有800×600设置/出发与暂停设置实拍。

## 电梯楼层导览

`combat/ElevatorPanel.ts` 复用同一组深蓝书封/徽章，采用双列楼层目录与小屏自适应布局。当前/锁定层禁用，可前往层支持数字键与鼠标，楼层规则仍来自BattleScene。面板不暂停世界，WASD继续传递；Esc/继续步行收起本次访问，离开电梯再进入可重新打开。销毁时清理键盘监听。10组浏览器检查报告为 `artifacts/archive-ui/elevator-verification.json`，另有1280/800/390px实拍及真实战斗乘梯截图。
