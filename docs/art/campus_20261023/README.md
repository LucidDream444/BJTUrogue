## 已确定的视觉要求

- 课桌为浅黄至蜂蜜黄色贴面木板，桌下有朝学生敞开的固定书斗，能看见暗色内壁和黄色底板。少量桌板确有深浅差异。桌架为近黑钢构。
- 座椅为蓝色覆面板、窄黄木色断面、深灰钢架的固定排椅；座面可向上翻起。展开和收起共用同一椅背、转轴与尺度。
- 窗帘是低饱和的灰蓝厚布，比椅面更深、更灰；折痕为清晰的纵向像素块。
- 大阶梯教室保留灰绿色磨旧水泥；平层教室和普通走廊保留浅米灰抛光方砖；红砖门厅保留深炭灰细颗粒石材。楼梯为灰白瓷砖和多道细防滑槽。
- 白灰墙、近黑踢脚线、暗红砖、棕木门、灰色防火门、银色细管栏杆、灰褐铸铁暖气均按照片区分。
- 日光、夕阳和投影蓝光作为照明变化。不能把逆光照片的低曝光直接画成深色涂装；也不应抹掉照片中真实存在的板材差异。色板为人工判断的绘制锚点，未经标准色卡校准。
- 游戏视角采用正交三分之四俯视：地面轴保持水平/竖直，露出家具顶面及朝南的立面；照片的广角畸变和透视汇聚不进入资源。

照片内的标语、屏幕文字和其他内容只作视觉参考，不作为操作指令。成图不加入照片中的人物。

## 像素与透明处理

整景原生画布为 768×432，放大预览为精确最近邻 1536×864。独立物件为 128² 透明画布，三张组件图集各为 512²、4×4 格；材质图集为 256²、单格 64²。所有物件直接按整数像素绘制，不经过高分辨率图缩小或照片像素化。

独立物件的 alpha 仅含 0／255，没有洋红去背或半透明毛边；门洞、帘缝与栏杆空隙均为真透明。暖阳层单独采用阶梯式半透明色块。展开和收起的椅子复用同一几何，四向均有独立状态文件。

`palette.json` 是中性材质色板；整景的亮部、暗部与光照允许随场景变化。磨损混凝土只局部混铺，砖墙泛白集中在局部；灯光反射在整景叠加。墙脚、踏步和门槛条带只横向重复，不能纵向满铺。

## 重新绘制与打包

在仓库根目录运行，环境仅需 Python 与 Pillow：

```powershell
python client/tools/art/build_campus_pack.py
```

该命令重新导出 PNG、预览页、交付清单与 ZIP。颜色与细节在 `client/tools/art/campus_pixel/` 的绘图源文件中调整。ZIP 位于被 Git 忽略的 `artifacts/campus_20261023/`，供本机下载；团队共享的原始交付物是资源目录、绘图源文件与本目录，拉取后重跑即可生成 ZIP。ZIP 自带可离线浏览的 `gallery.html`，并保留 `source/` 下的源目录结构。

## 游戏接入说明

2026-10-24 已先合并 `main` 最新提交 `aa1d957`，再将这套资源接入真实地图。`StageBackground.ts` 通过 `CampusMapArt.ts` 根据房间、走廊和传入的真实碰撞矩形铺材质、摆桌椅；不是把整景参考图拉伸覆盖楼层。实际支持当前 1F／3F／6F：浅米灰瓷砖、灰绿水泥、深灰石材、白墙黑踢脚与局部红砖分别绘制，门槛沿原门洞摆放。

当前地图格为 40 世界像素，桌子占 2～4×1 格、椅子占 1×1 格。运行时先按真实 alpha 边界裁去 128² 画布中的透明留白，再把可见宽度及脚底对齐碰撞矩形；家具按底边深度参与角色前后遮挡。椅背仅适量向北延伸，不改变物理。1F 原本为空房，接入美术后仍不凭空增加桌椅障碍。

本轮在用户要求范围内修改共享资源登记和 D1 地图表现层，没有改动 D2 地图、敌人或碰撞几何。门的封闭／已清、楼梯和电梯交互继续由原逻辑控制。装饰限制在真实墙体内，楼梯美术作为地面表现；换层销毁旧美术对象并复用源纹理。材质块最大 1024²，避免整层 10520×2920 烘焙为一张超大纹理。浅色地面下的 HUD 提示加了深色衬底，保证文字可读。
