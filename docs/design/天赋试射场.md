# 天赋试射场：操作与范围

日期：2026-11-20。测试场 ID：`d1_talent_playground`。

在 `client/` 运行 `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`，打开 `http://127.0.0.1:5174/test.html?arena=d1_talent_playground`。

进入后默认自动演示。鼠标在场内按住左键可接管射击；WASD 或方向键移动，鼠标瞄准。上方按钮或数字 1—5 切换组合，6 为普通射击。右侧三张天赋可分别开关；Q 在落雷天赋生效时主动落雷。空格/暂停按钮暂停，R 或重置按钮重置，Esc 返回测试场目录。

| 组合 | 可试的行为 |
|---|---|
| 裂变蜂群 | 分裂子弹会继续追踪；关闭追踪后比较小弹能否打中 |
| 跳弹风暴 | 朝上下边墙射击，观察三发子弹反弹后穿透靶标 |
| 暴击雷网 | 暴击触发落雷并连到附近靶标；Q 也可主动放雷 |
| 回旋星环 | 移动改变子弹返程路径，靠近靶标让环绕星弹命中 |
| 黑洞聚爆 | 主弹命中后聚拢附近靶标，延迟引爆；可单关黑洞对照 |

靶标有真实血量，可击杀、自动补充，不攻击玩家。本场验证弹丸、触发、伤害、组合直观感受，未接入正式地牢选卡、正式怪物 AI、角色受伤和存档；它是独立实验，不代表正式武器的完整平衡。

玩法数值全部在 `client/public/config/talent-playground.json`。本场用 75% 分裂、两颗追击弹等更明显的实验数值，优先便于观察；这些覆盖上版方案的测试数值，仅影响本场，不修改正式 `combat.json/rewards.json`。

实现全部在 `client/src/test/arenas/D1/`：`d1_talent_playground.ts` 继承统一底座，纯模拟 `_TalentPlaygroundModel.ts`、界面 `_TalentPlaygroundUi.ts`、样式 `_talent-playground.css`。采用程序几何和 SVG 图标，没有引入外部美术。没有修改正式入口、共用测试场底座或其他域。

模型单测覆盖高速扫掠、可复现重置、普通射击、分裂不递归、弹丸/特效上限、单卡开关、落雷冷却、回旋与环绕、黑洞、长帧钳制。浏览器实测覆盖五组击杀、单卡切换、普通射击、暂停、WASD、按住左键、Q、快捷键、重启清理、窗口缩放；运行异常为 0。浏览器证据与截图保存在 `output/talent-playground/`，包括 `browser-check.json`。
