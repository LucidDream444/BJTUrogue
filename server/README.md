# server/ — 服务端（D5 负责）

> **本目录目前是空的，是一处预留位，不是任何人的既有实现。**

按《技术选型》§6，这里将来放 **Django 5 + DRF + Django Admin + PostgreSQL** 的服务端，
包含反馈 API、遥测 API、账号与 RBAC、以及 Django Admin 后台。

- **归属**：D5 服务端与运维域。目录内的一切由 D5 创建和维护。
- **状态**：D5 尚未开工（按《人员分工方案》§7，服务端从第 5 周 S0 阶段开始）。
- **不要**在这里放客户端代码；客户端的全部内容在 `client/`。

## 为什么现在就有这个目录

仓库在 2026-10-12 从空的初始化状态改为 `client/` + `server/` 的双子项目布局：
客户端与服务端是两套完全不同的工具链（npm/Vite vs pip/Django），分目录后
根目录保持干净，两边的依赖、配置、构建产物互不干扰，也避免了将来把
`node_modules/` 和 `.venv/` 混在同一个根下。
